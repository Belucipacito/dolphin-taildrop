# dolphin-taildrop

Taildrop for the KDE Dolphin file manager. Right-click any file or folder,
pick a device on your tailnet, and send it.

## Requirements

Tailscale, systemd, Python 3 with PyQt6, PySide6 or PyQt5, and KDE Plasma 5 or 6.

## Usage

    ./taildrop-dolphin.sh install
    ./taildrop-dolphin.sh uninstall
